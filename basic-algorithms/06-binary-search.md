## Problem: Binary Search (Easy)

**Link:** https://leetcode.com/problems/binary-search/

### Approach

I used the binary search technique on the sorted array.
I repeatedly checked the middle element and reduced the search range based on the target value.

### Complexity

- Time: O(log n)
- Space: O(1)

### Notes

Tested with a target that exists in the array and a target that does not exist.
